# Melody_Game 🎵

Уеб базирана игра за запомняне на мелодии, свързана с ESP32 и бузер.

## Описание

Играчът трябва да повтори мелодията, генерирана от системата. При всяко успешно повторение нивото се увеличава и мелодията става по-дълга.

## Функции

- Генериране на случайни мелодии
- Нива на трудност
- Система за точки
- Животи
- Възпроизвеждане на звуци чрез ESP32 и бузер
- Уеб интерфейс за управление

## Използвани технологии

- HTML
- C++
- Arduino IDE

## Хардуер

- ESP32
- Пиезо бузер
- USB захранване

## Свързване

| Компонент | ESP32 |
|-----------|--------|
| Бузер (+) | GPIO 25 |
| Бузер (-) | GND |

## Стартиране

1. Качете кода в ESP32 чрез Arduino IDE.
2. Стартирайте уеб приложението.
3. Натиснете бутона "Нова мелодия".
4. Повторете изсвирената мелодия.
